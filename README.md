# 🛡️ Devion Guard

**Devion Guard** é um bot de segurança para servidores Discord, desenvolvido para proteger, monitorar e manter comunidades organizadas.

> **Devion Guard • Segurança em primeiro lugar.**

## 🛡️ Recursos

- 🛡️ **Anti-Raid** — detecta entradas rápidas de membros e ativa proteção temporária
- 🤖 **Anti-Bot** — remove bots não autorizados
- 🚫 **Anti-Spam** — detecta flood e mensagens repetidas
- 🔗 **Anti-Link** — bloqueia links não permitidos
- 📩 **Anti-Invite** — bloqueia convites de outros servidores
- 💥 **Anti-Nuke** — monitora ações destrutivas
- 🗑️ **Proteção contra exclusões em massa** — monitora exclusões de canais e cargos
- 🚨 **Modo de emergência** — bloqueia temporariamente o envio de mensagens
- ✅ **Whitelist** — permite autorizar usuários e bots
- 📋 **Monitoramento** — registra eventos importantes para controle e segurança

## ⚙️ Tecnologias

- **Python**
- **discord.py**
- **Discord API**

## 🔐 Segurança

O Devion Guard utiliza variáveis de ambiente para armazenar informações sensíveis.

**Nunca coloque o token do bot diretamente no código ou publique tokens no GitHub.**

## 🚀 Desenvolvimento

O Devion Guard está em desenvolvimento contínuo.

Novos sistemas de proteção, melhorias e ferramentas de segurança serão adicionados ao projeto conforme seu desenvolvimento.
